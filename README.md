# Coding Test Preparation

## Overview

취업 준비 과정에서 기업 코딩테스트에 대비하기 위해 다양한 문제를 직접 해결하고, 풀이 과정과 학습 내용을 기록하는 Repository다.

특정 프로그래밍 언어에 제한을 두지 않고, 자료구조와 알고리즘에 대한 이해를 높이며 문제 해결 능력과 구현 역량을 향상시키는 것을 목적으로 한다.

## Focus

- 기업 코딩테스트에서 요구하는 문제 해결 능력 향상
- 자료구조 및 알고리즘의 이해와 활용
- 문제 분석 및 해결 방법 설계
- 시간 복잡도와 공간 복잡도를 고려한 구현
- 제한 시간 내 정확하고 효율적인 코드 작성
- 오답 및 비효율적인 풀이의 원인 분석과 개선

## Tech Stack

특정 프로그래밍 언어나 실행 환경에 제한을 두지 않는다.

지원 기업의 코딩테스트 환경과 문제 특성에 따라 언어를 선택하며, 실제 사용한 언어와 실행 환경은 문제 풀이 코드와 함께 관리한다.

## Scope

### Planned

- 알고리즘 및 자료구조 문제 풀이
- 기업 코딩테스트 유형에 따른 문제 해결 연습
- 풀이 방법과 시간·공간 복잡도 분석
- 오답 및 개선 사항 기록
- 필요한 경우 동일 문제의 언어별 구현 비교

## Directory Structure

문제 풀이 코드는 프로그래밍 언어와 문제 제공 플랫폼을 기준으로 분류한다.

```text
01-coding-test-preparation/
├── README.md
├── javascript/
│   ├── programmers/
│   └── baekjoon/
├── python/
│   ├── programmers/
│   └── baekjoon/
├── java/
│   ├── programmers/
│   └── baekjoon/
└── rust/
    ├── programmers/
    └── baekjoon/
```

위 구조는 예시이며, 실제 사용하는 언어와 문제 제공 플랫폼에 따라 디렉터리를 추가한다.

## AI Usage

**Mode: manual**

문제 분석과 해결 방법 설계, 구현 코드는 직접 작성한다.

AI는 알고리즘 개념 확인, 언어별 문법 및 표준 라이브러리 확인, 작성한 코드의 검토와 개선 방향을 파악하는 보조 목적으로 활용한다.

실제 기업 코딩테스트에서는 해당 기업의 AI 도구 사용 정책을 따른다.
